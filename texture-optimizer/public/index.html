🚗 FiveM Texture Optimizer

Make cars, clothing & MLO textures smaller so your server loads faster and stutters less.

⚙️ One-time setup — connect CodeWalker / GTAUtil so it can optimize .ytd packs

Cars, clothing and MLOs keep their textures packed inside .ytd files. To let this tool open, optimize and repack them automatically, point it at gtautil.exe — a free CodeWalker-based command-line tool. Without this, the tool still optimizes loose textures and lists your .ytd files so you can do them by hand.

Don't have it? Search “GTAUtil” on GitHub and download the release, then paste the path to gtautil.exe above. (Any compatible CodeWalker CLI works — advanced users can tweak the commands in config.json.)

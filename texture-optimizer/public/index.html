Optimizing .ytd packs

Finished car / clothing / MLO textures live packed inside .ytd files. Repacking a .ytd safely needs a tool that understands that format — and there is no simple free command-line tool that does it. (GTAUtil does not support .ytd textures, and OpenIV has no command line.) So sxn opti can't rewrite .ytd files by itself.

The reliable way to optimize a .ytd:

  1. Open the .ytd in OpenIV or CodeWalker and export its textures (as .dds).
  2. Run those exported textures through sxn opti (just scan that folder).
  3. Import the optimized .dds back into the .ytd and save.

Or use a purpose-built app like ToolKitV, which optimizes textures inside .ytd for you. sxn opti still scans your .ytd files and shows the biggest ones so you know which to fix.

Advanced — connect a .ytd command-line tool (optional)

Only if you have a CLI that can extract & rebuild .ytd texture dictionaries (a custom CodeWalker.CLI build, etc.). GTAUtil will not work here. The exact commands live in config.json next to the tool — adjust them to match yours.

About

sxn opti resizes oversized textures, compresses them with the right DDS/BC format, and builds mipmaps — cutting VRAM use and texture-streaming stutter. It does this automatically for loose textures (.dds .png .jpg .tga .bmp); .ytd packs use the workflow above. Runs entirely on this PC.
